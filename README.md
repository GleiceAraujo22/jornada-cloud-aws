## 🎯 Sobre o projeto

Este repositório documenta minha jornada de aprendizado em computação em nuvem, reunindo conceitos teóricos, anotações técnicas, laboratórios práticos e projetos desenvolvidos ao longo dos estudos.

Meu objetivo é construir uma base sólida em cloud computing, compreender os principais serviços da AWS e explorar aplicações da computação em nuvem no ecossistema de dados.

Mais do que reunir anotações, este projeto busca registrar minha evolução técnica, as dificuldades encontradas, os experimentos realizados e os conhecimentos construídos ao longo do caminho.

## 🧪 Como documento meu aprendizado

Cada tópico poderá incluir:

- **Conceito:** explicação com minhas próprias palavras.
- **Aplicação:** problema que a tecnologia resolve.
- **Prática:** exercícios, configurações e laboratórios realizados.
- **Aprendizados:** descobertas, dificuldades e pontos para revisar.
- **Referências:** documentação oficial e materiais utilizados.

## 💡 Conexão com a área de dados

Ao longo dos estudos, pretendo explorar como os serviços de cloud podem ser aplicados ao armazenamento, processamento e análise de dados, conectando os fundamentos da nuvem a conceitos de engenharia de dados e analytics.
